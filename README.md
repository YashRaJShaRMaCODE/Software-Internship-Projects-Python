# Data Analytics Internship Projects – Cognetix Technology

## Overview
This repository contains projects completed as part of the Data Analytics Internship
at Cognetix Technology. The projects are divided into Foundational and Intermediate stages.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Project Stages

### Foundational
- Sales Data Analysis
- Student Performance Analysis
- COVID-19 Data Analysis

### Intermediate
- E-Commerce Dataset Analysis
- Bank Customer Churn Analysis
- Interactive Sales Dashboard

## Outcome
These projects demonstrate practical data handling, exploratory data analysis,
data visualization, and business insight generation skills.
